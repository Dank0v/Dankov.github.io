CircuitSim

MINECRAFT FORGE MOD  //  v1.4.0  //  MC 1.20.1

Build and simulate real electronic circuits inside Minecraft.

[ OVERVIEW ]

CircuitSim is a Minecraft Forge mod that turns the world into a breadboard. Place component blocks, wire them together, and right-click the Simulate Block to run a full SPICE simulation powered by ngspice — real node voltages and branch currents, plotted in-game.

It covers passives, independent and controlled sources, diodes, switches, IC-level MOSFETs with SKY130A PDK support, and even user-defined subcircuits you can build once and reuse as a black box. Operating point, AC, transient and noise analyses are all supported, with parameter and temperature sweeps overlaid on the graph.

[ DEMOS ]

[ HIGHLIGHTS ]

Real SPICE Engine

ngspice runs as a subprocess on the extracted netlist — actual voltages and currents, not a Redstone approximation.

Full Component Set

R / L / C, DC / SIN / PULSE sources, diodes, voltage-controlled switches, and all four controlled sources (E/G/H/F).

IC / PDK Devices

4-terminal IC NMOS/PMOS and IC passives with SKY130A PDK, a generic PDK, and free-form .include for custom libs.

Every Analysis

.OP, .AC, .TRAN and .NOISE, plus parameter and temperature sweeps overlaid as labelled curves on the graph.

User Subcircuits

Turn any circuit you build into a real SPICE .subckt and reuse it as a portable black-box chip item.

In-Game Graphing

Plot two probes at once with hover tooltips, log-axis AC sweeps, and an FFT button for any transient trace.
